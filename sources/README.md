## 归档结构

每个 `examples/<作者>__<仓库>/` 对应一个固定上游提交的文件快照；子目录中的原始文件与 Git 文件模式保留。`catalog.json` 中的 `commit` 与 `tree` 是上游提交和根目录树的完整 SHA，`files` 与 `bytes` 统计该快照的 Git blob 文件数和总字节数。依赖安装目录和本地 Git 管理目录不属于上游源码快照。

运行命令依据上游 README、包清单与页面入口整理，本次归档没有执行这些项目。数据与源码路径均保持在项目自身目录内，便于按上游方式单独安装、查看和修改。
